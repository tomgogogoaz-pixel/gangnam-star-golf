# 강남스타피트니스골프 홈페이지

역삼동 테헤란로 골프 · 피트니스 센터 **강남스타피트니스골프**의 반응형 홈페이지입니다.
Next.js로 만들었고 Vercel에 무료로 배포합니다.

## 내 컴퓨터에서 켜 보기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 무엇을 어디서 고치나요

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 전화번호, 카카오톡 채널 주소, 주소, 운영시간, 가격, 공지 | `lib/site.ts` |
| 화면 구성 (섹션 순서, 문구 배치) | `app/page.tsx` |
| 색, 글자 크기, 움직임 | `app/globals.css` |
| 로고 | `public/logo.png` |

### 카카오톡 상담 연결
`lib/site.ts`의 `kakaoChannelUrl`에 채널 채팅 주소를 넣으면 모든 카카오톡 버튼이 연결됩니다.
(예: `https://pf.kakao.com/_abcdE/chat`) 비어 있으면 전화 걸기로 연결됩니다.

### 사진 · 영상 넣기 (나중에)
1. 사진을 `public/images/` 폴더에 넣습니다. (예: `hero-1.jpg`)
2. `lib/site.ts`에서 해당 항목에 `image: "/images/hero-1.jpg"`를 추가합니다.
   메인 슬라이드는 `video: "/images/hero.mp4"`도 됩니다 (무음 반복).

필요한 사진 목록: 메인 슬라이드 3장(타석 전경 · 레슨 장면 · 헬스장 전경), 프로그램 3장(GOLF · FITNESS · PT),
센터 특징 4장(타석 · 스윙 분석기 · 개인 부스 · 샤워실/라커).
AI 합성 이미지 대신 실제 촬영 사진을 씁니다. 가로 사진, 1920px 정도면 충분합니다.

## 구성

풀페이지 메인 (섹션 = 한 화면, 스크롤하면 섹션 단위로 맞춤)

1. 메인 슬라이드 (6초 자동 넘김, 천천히 줌아웃)
2. GOLF / FITNESS / PT 3분할 (마우스 올린 칸이 넓어지고 사진 확대)
3. 센터 특징 4가지
4. 회원권
5. 소식 + 네이버 블로그
6. 오시는 길

항상 떠 있는 것: PC는 오른쪽 카톡상담 · 전화문의 · TOP, 모바일은 아래 전화 · 카카오톡 버튼.

폰트: 한글 Gothic A1, 영문 Montserrat (Google Fonts, `next/font`로 자체 호스팅)

## 보안 · 데이터

- 상담은 **카카오톡 채널 1:1 채팅과 전화**로만 받습니다. 사이트에 입력 폼 · 회원가입 · DB가 없어서
  고객 개인정보를 이 사이트가 저장하지 않습니다. 상담 기록은 카카오톡 채널 관리자센터에 남습니다.
- 서버 코드가 없는 정적 페이지라 해킹 대상이 될 곳이 거의 없습니다.
- `next.config.ts`에 보안 헤더(다른 사이트에 끼워 넣기 차단, 외부 스크립트 차단 등)를 넣어 두었습니다.
- `.env` 같은 비밀 파일은 GitHub에 올리지 않도록 `.gitignore`에 적어 두었습니다.
